# وكيل أرافيك ذكاء لقناة YouTube

هذا المشروع يبدأ بإنتاج **مسودة فيديو عربية** عبر GitHub Actions وحفظها كملف Artifact للمراجعة. لا يرفع أو ينشر الفيديو تلقائيًا في هذه المرحلة، حتى لا يُنشر محتوى غير مُراجع.

## ما الذي يفعله الآن؟
- ينشئ فيديو عموديًا قصيرًا باللغة العربية عن الذكاء الاصطناعي.
- يولّد تعليقًا صوتيًا عربيًا باستخدام Edge TTS.
- يركّب الفيديو باستخدام FFmpeg.
- يحفظ الفيديو والنص كـ Artifact في تشغيل GitHub Actions.

## التشغيل من الهاتف
1. افتح تبويب **Actions** في المستودع.
2. إذا ظهر زر **I understand my workflows, go ahead and enable them** فاضغطه.
3. افتح **Generate Arabic video draft** ثم **Run workflow** لتشغيله يدويًا.
4. بعد انتهاء التشغيل، افتح النتيجة ونزّل Artifact باسم `aravicai-video-draft`.

هناك تشغيل مجدول أسبوعيًا، لكن GitHub قد يؤخر بدء المهام المجدولة.

## تنبيه مهم
- هذا إصدار أولي لإنتاج المسودات فقط؛ **لا يوجد رفع إلى YouTube بعد**.
- النشر التلقائي يحتاج إعداد YouTube Data API وOAuth بطريقة آمنة، ثم اختبار الرفع كـ Private قبل الجدولة العامة.
- لا تضع مفاتيح API أو رموز OAuth داخل الكود أو ملفات المستودع.
- راجع دقة المعلومات وحقوق الصور والصوت وسياسات YouTube قبل النشر. لا تكرر محتوى آليًا منخفض القيمة بغرض تحقيق الدخل.
